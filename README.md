# Edge Walkers — 가장자리를 걷는 폰 배경화면

작은 캐릭터들이 폰 화면의 **네 변과 모서리를 따라** 돌아다니며, 가끔 멈춰서 두리번거리고 앉고 졸고 점프합니다.
**내가 직접 만든(또는 가진) 이미지 프레임**을 넣으면 어떤 캐릭터든 같은 움직임으로 걷습니다.

- 단일 파일 `index.html` (외부 의존성 0, 오프라인 동작)
- 내장 데모는 오리지널 2종뿐입니다: **말랑 떡 슬라임**(`slime`), **꼬마 유령**(`ghost`). 코드로 직접 그린 그림입니다.
- 움직임(가장자리 걷기·모서리 회전·멈춤)만 참고했고, 기존 작품의 캐릭터는 그리거나 포함하지 않았습니다.
  **저작권이 있는 캐릭터 이미지는 직접 넣어 쓰는 경우에도 본인 책임**입니다. 개인 소장·비공개 용도로만 쓰세요.

## 빠른 시작

```bash
npm install              # 처음 한 번 (playwright — 테스트·영상 녹화용, 앱 자체는 필요 없음)
node build.mjs           # src/ → index.html 단일 파일 생성
node scripts/serve.mjs   # http://127.0.0.1:5173 (폴더 방식은 서버가 필요)
```

`index.html` 을 그냥 더블클릭(`file://`)해도 내장 데모와 **앱 안에서 추가한 캐릭터**는 동작합니다.
다만 브라우저가 `file://` 에서 `fetch` 를 막기 때문에 **`sprites/` 폴더 방식은 서버로 열어야** 합니다.

조작:
| 동작 | 결과 |
|---|---|
| 캐릭터 근처를 탭 | 가까운 개체가 점프 |
| 화면을 **길게 누르기**(0.6초, 손가락 움직이지 않기) 또는 우하단 ⚙ | 설정 패널 |
| 패널 바깥(위쪽) 탭 | 패널 닫기 |

## 스프라이트 규격

| 액션 | 필수 | 권장 프레임 | 최소 | 없을 때 대체 |
|---|---|---|---|---|
| `walk` 걷기 | **필수** | 4 | 2 | — |
| `idle` 멍때리기 | **필수** | 2 | 1 | — |
| `look` 두리번 | 선택 | 2 | 1 | idle |
| `sit` 앉기 | 선택 | 1~2 | 1 | idle |
| `jump` 점프 | 선택 | 3 (웅크림·공중·착지) | 1 | idle (걷던 자리에서 위로 뛰는 연출) |
| `sleep` 잠자기 | 선택 | 2 | 1 | sit → idle |

이미지 규칙
- **투명 PNG**(WebP 도 가능). 한 캐릭터의 **모든 프레임은 같은 캔버스 크기**(권장 256×256).
- **옆모습, 오른쪽을 바라보게**, 바닥을 걷는 자세로 그립니다. 엔진이 좌우 반전·벽/천장 회전·모서리 보간을 처리합니다.
- **발 접지선은 캔버스 아래쪽 같은 높이, 가운데 정렬**(256 캔버스라면 y≈224, x=128). `sprites/_template/guide.png` 에 기준선이 그려져 있으니 레이어로 깔고 그리세요.
- 진행 방향은 화면 기준 반시계(바닥→오른쪽 벽→천장→왼쪽 벽)이며 개체마다 가끔 뒤돌아 걷습니다.
- 규격을 어기면(걷기 1장, 크기가 다른 프레임 등) 앱이 이유를 알려주고 저장을 막습니다.

## 방법 1: 폴더에 넣기 (`sprites/`)

```
sprites/
  내캐릭터/
    walk_1.png  walk_2.png  walk_3.png  walk_4.png
    idle_1.png  idle_2.png
    look_1.png  look_2.png      ← 선택
    character.json              ← 선택
```

- 파일명은 `<액션>_<번호>.png`, 번호는 **1부터 빠짐없이** 이어져야 합니다(끊기면 그 앞까지만 사용).
- 폴더 이름이 캐릭터 id 입니다. `_` 로 시작하는 폴더(`_template`)는 무시됩니다.
- `character.json` (전부 선택):
  ```json
  { "name": "내 캐릭터", "scale": 1, "speed": 60, "fps": 8, "count": 2 }
  ```
  `scale` 크기 배율 · `speed` 걷기 속도(px/s, 390px 폭 기준) · `fps` 프레임 속도 · `count` 마릿수.
- 폴더를 바꾼 뒤에는 **목록 파일을 다시 만들어야** 합니다 (정적 파일은 폴더를 읽을 수 없어서):
  ```bash
  node scripts/gen-manifest.mjs     # sprites/manifest.json 생성
  ```
- 내장 데모와 같은 id(`slime`, `ghost`)의 폴더가 있으면 폴더가 우선합니다.
  데모 PNG 는 `node scripts/export-demo-sprites.mjs` 로 `sprites/slime`, `sprites/ghost` 에 저장되어 있어 그대로 참고용 예시가 됩니다.

## 방법 2: 앱 안에서 추가 (사진첩에서 선택)

1. 화면을 길게 누르거나 ⚙ 를 눌러 설정을 엽니다.
2. **+ 캐릭터 추가** → 이름 입력 → 액션별 **+ 이미지 선택(여러 장)** 으로 사진첩/파일에서 프레임을 고릅니다.
   여러 장을 한 번에 고르면 파일명 순서(자연 정렬)대로 1, 2, 3… 이 됩니다. 칸의 × 로 한 장만 뺄 수 있습니다.
3. 미리보기에서 액션별로 재생해 보고 크기·속도·fps·마릿수를 조절 → **저장**.

저장 위치는 브라우저의 IndexedDB 입니다(서버로 올라가지 않음). 새로고침·오프라인 후에도 유지됩니다.
폴더/내장 캐릭터는 이미지는 못 바꾸지만 크기·속도·fps·마릿수는 조절되고(기본값으로 되돌리기 가능), 켜고 끌 수 있습니다.
배경(단색·그라디언트·내 사진)도 설정 패널에서 바꿉니다.

### 내보내기 / 가져오기
설정 → **내보내기 (JSON)** 으로 내 캐릭터를 하나의 `edge-walkers-characters.json` 파일(이미지는 base64)로 저장하고,
다른 기기/브라우저에서 **가져오기**로 불러옵니다. id 가 겹치면 새 id 로 추가됩니다. 브라우저 데이터를 지우면 저장된 캐릭터도 사라지니 백업용으로 쓰세요.

## 친구에게 공유하기 (링크 하나로)

내가 넣은 캐릭터를 **링크 하나**로 아이폰 친구에게 줄 수 있습니다. 받는 사람은 앱 설치도 파일 전달도 필요 없습니다.

**보내는 법**
1. 설정(길게 누르기 또는 ⚙) → **공유 링크 만들기**.
2. 보낼 캐릭터를 고르고(기본: 내 캐릭터 전부), 필요하면 **현재 배경 포함** 을 켜거나 끕니다.
3. **링크 만들기** → `팩 만드는 중…` → `올리는 중…` → `완료!`. 공유 시트가 뜨면 카톡 등으로 보내고, 안 뜨면 **공유하기** / **링크 복사** 버튼이나 화면에 표시된 링크를 쓰세요.

링크는 `https://456rtyfgh.github.io/edge-walkers/?pack=<12자리 번호>` 모양입니다.

**받는 법**
1. 링크를 **Safari** 로 엽니다(카카오톡·인스타 안의 브라우저에서는 “Safari 로 열기”를 먼저). 열자마자 캐릭터와 배경이 들어가고 “캐릭터 N개 받았어요” 라고 알려줍니다. 같은 링크를 다시 열어도 중복으로 들어오지 않습니다.
2. 앱처럼 쓰려면 Safari 의 **공유 버튼 → 홈 화면에 추가 → 추가**. 처음 열면 이 순서를 알려 주는 안내가 뜹니다(닫기 / 다시 안 보기 가능).
3. 홈 화면 아이콘으로 열면 주소창 없는 전체화면 앱이 됩니다. 인터넷 없이도 실행됩니다(서비스 워커 캐시).

**알아두기**
- iOS 는 Safari 와 홈 화면 앱의 저장소가 **분리**되어 있어, 홈 화면 앱은 처음에 빈 상태일 수 있습니다. 그래서 홈 화면에 추가할 때 시작 주소에 `?pack=` 이 유지되도록 했고, 그래도 비어 있으면 앱 안에서 받은 링크를 붙여넣을 수 있습니다. 자세한 조사와 한계는 `docs/ios-pwa-notes.md`.
- **링크를 아는 사람은 누구나** 팩을 볼 수 있습니다(공개 저장소). 올린 팩은 **지우거나 덮어쓸 수 없습니다.** 남에게 보여 주기 싫은 이미지는 올리지 마세요. 저작권이 있는 캐릭터의 공유는 본인 책임입니다.
- 용량 한도: 팩 1개 최대 **8 MB**, 캐릭터 20개, 액션당 프레임 8장. JPEG 등은 PNG 로 변환되어 올라갑니다. 초과하면 “용량이 너무 커요” 라고 알려 주니 캐릭터를 줄이거나 배경을 빼 보세요.
- 받은 팩은 형식·크기·이미지 종류(PNG/WebP 만)를 검사하고, 이름 등 글자는 텍스트로만 표시합니다.

## 데모 영상 만들기 (MP4)

```bash
node scripts/install-browser.mjs   # Chromium 을 이 폴더 node_modules 안에 설치 (한 번만)
npm run record                     # out/demo.mp4 : 1179×2556, 30fps, 10~15초, 무이음 루프
```

- 1179 는 홀수 폭이라 `yuv420p` 로 인코딩할 수 없어서, 기본 출력은 정확히 1179×2556 **`yuv444p`** 입니다. 맥 QuickTime·폰에서 재생이 안 되면
  `npm run record -- --ext` 로 1180×2556 `yuv420p`(오른쪽 1px 검은 패딩) 버전을 다시 만드세요. 옵션: `--seed 7 --dur 12 --chars slime,ghost --out out/demo.mp4`.

`index.html?record=1&seed=7&loop=12&chars=slime,ghost&hideUI=1` 로 결정론적 녹화 모드가 켜집니다 (같은 seed 면 같은 영상).
녹화는 `sprites/` 폴더 캐릭터를 쓰므로, 내 캐릭터를 영상에 넣으려면 폴더에 넣고 `gen-manifest` 후 `chars=` 에 id 를 추가하세요. `ffmpeg` 가 필요합니다.

## 폰 배경화면으로 쓰기 — 솔직한 한계

웹앱은 폰의 **진짜 배경화면 슬롯에 들어갈 수 없습니다.** 가능한 방법은 다음과 같습니다.

- **아이폰**: iOS 는 배경화면에 영상을 직접 지정할 수 없습니다. 영상을 **Live Photo 로 변환**(앱 필요)해 쓰면 잠금화면에서 길게 눌러야 재생되고, 홈화면에서는 정지 이미지입니다.
  가장 현실적인 방법은 호스팅한 페이지(https://456rtyfgh.github.io/edge-walkers/)를 Safari 에서 **홈 화면에 추가**해 전체 화면으로 띄워 두거나, 화면 녹화로 영상을 만들어 쓰는 것입니다.
  홈 화면 앱은 Safari 와 저장소가 분리되어 있으니, 캐릭터는 공유 링크(`?pack=`)로 받은 뒤 추가하세요(위 “친구에게 공유하기”).
- **안드로이드**: 기기·런처에 따라 **동영상 배경화면** 앱(또는 삼성 갤럭시의 동영상 잠금화면 등)으로 `out/demo.mp4` 를 반복 재생할 수 있습니다.
- 어느 쪽이든 MP4 는 10~15초 무이음 루프라서 반복 재생 앱에 넣기 좋습니다. 배터리 소모가 있으니 필요할 때만 쓰세요.
- 호스팅(GitHub Pages 등)해서 쓸 때는 `index.html`, `sprites/`, 설치용 부속(`manifest.webmanifest`, `sw.js`, `icons/`)을 함께 올리세요. `out/*.mp4` 는 repo 에 포함되지 않으니 `npm run record` 로 직접 만듭니다.

## 개발

```bash
node build.mjs                      # index.html 생성 (직접 편집 금지, src/ 를 고치세요)
node tests/settings.spec.mjs        # 폴더·패널 로드, 저장 유지, 내보내기/가져오기 검증 (스크린샷: tests/shots-settings/)
npm test                            # 엔진 검증(스크린샷: tests/shots/)
node tests/share.spec.mjs           # 공유 링크 UI 흐름 (인터넷 필요, test… 팩 1개 업로드)
node tests/a2hs.spec.mjs            # iOS 홈 화면 추가 안내 오버레이 (WebKit: node scripts/install-browser.mjs webkit)
node scripts/check-secrets.mjs      # 커밋 대상에 토큰·secret 키가 없는지 검사
node scripts/deploy.mjs             # 검사 → 빌드 → 커밋 → 공개 repo 푸시 → GitHub Pages 켜기 → 200 확인
```

배포는 `~/Documents/.tools/secrets/github.token` 의 토큰을 메모리에서만 쓰며(로그·`.git/config`·원격 URL 에 저장하지 않음) Pages 활성화가 권한 문제로 실패하면 응답을 그대로 출력하고 멈춥니다.

구조: `src/store.js`(IndexedDB) · `loader.js`(폴더) · `io.js`(JSON) · `demo-chars.js`(데모 그리기) · `path.js`/`behavior.js`/`engine.js`(걷기 엔진) · `ui.js`/`ui.css`(설정 패널) · `share.js`(공유 링크 만들기·업로드) · `a2hs.js`(홈 화면 추가 안내) · `config.js`/`pack.js`/`toast.js`(받기·검증) · `main.js`(조립).
테스트용 도형 캐릭터는 `tests/fixtures/` 에만 있으며 앱 폴더(`sprites/`)에는 섞이지 않습니다.
